## The grammar

```
S:<plan>,<plan>,<plan>:<material>      a stack, one plan per third
A:<axis><hand>:<plan>:<material>       an arch: piers, then the vault
<plan>/<q>                             quarter-turned q times
hand: + both spandrels · l left · r right
```

A plan may be **added** freely: no existing recipe mentions it, so no existing
block changes. A plan may **not** be renamed or removed without breaking every
recipe that names it — `decode` reports those rather than substituting.
