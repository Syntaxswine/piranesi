`docs/kit-spec.json`, which is the role spec this is built from, and re-run.

**100 blocks chosen from 66,920.** Not the top 100 by score: the census
says high scores cluster, so the top hundred would be one idea a hundred
times. These are picked to work **together** — see `js/kit.js`.

> Choose each block for what it lets the NEXT layer do — the ceiling that carries it, the edge word it hands sideways, and the base plan it can be set down on — because the cube law already made joinery near-universal (10,806 of 10,826 fully flush) so "does it join" ranks nothing, while vertical continuation, edge-word bridging and a solid cap are scarce, and the composite score is blind to all three.

about the pick — and four of them are arches, which is BACKLOG 0f in another
costume: a vault runs but it cannot land, so its spandrel wall is met by
almost nothing. A springer would close those four and nothing else will.

**And the cost, said out loud.** Every swap trades an odd wall for a common
one, so distinct wall patterns in the kit fell from 55 to 49: eight more
blocks fully flush, six fewer kinds of seam. That is the right trade for a kit
whose job is to tile — but it is a trade, and a pass that reported only the
number it was optimising would have hidden it.
