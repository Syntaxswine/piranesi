**100 blocks chosen from 45,276.** Not the top 100 by score: the census
says high scores cluster, so the top hundred would be one idea a hundred
times. These are picked to work **together** — see `js/kit.js`.

> Choose each block for what it lets the NEXT layer do — the ceiling that carries it, the edge word it hands sideways, and the base plan it can be set down on — because the cube law already made joinery near-universal (10,806 of 10,826 fully flush) so "does it join" ranks nothing, while vertical continuation, edge-word bridging and a solid cap are scarce, and the composite score is blind to all three.
